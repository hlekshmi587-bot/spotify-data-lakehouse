```sql
-- Country averages are re-weighted by matched_entries so a big country counts more than a small one.

       count(*)                                                        as countries,
       sum(matched_entries)                                            as matched_entries,
       round(sum(avg_danceability * matched_entries) / sum(matched_entries), 3) as danceability,
       round(sum(avg_energy       * matched_entries) / sum(matched_entries), 3) as energy,
       round(sum(avg_valence      * matched_entries) / sum(matched_entries), 3) as valence,
       round(sum(avg_acousticness * matched_entries) / sum(matched_entries), 3) as acousticness,
```

## 08_mood_quadrant_by_chart
**What mood (valence x energy) do charted tracks have, per chart type?**

```sql
select ct.chart_type, t.mood_quadrant,
```

## 10_period_change_with_window
**How do average streams and valence move between the snapshot months? (window function: LAG)**

> **Caveat:** the snapshot months are far apart (2017-01, 2017-02, 2018-03 once tiny months are excluded), so 'change' means change between sampled months, not month-over-month.

```sql
select year_month, chart_entries, data_volume, avg_streams,
       round(avg_streams - lag(avg_streams) over (order by year_month), 1) as change_in_avg_streams,
       avg_valence,
       round(avg_valence - lag(avg_valence) over (order by year_month), 4) as change_in_valence
from {{ ref('mart_period_trends') }}
where chart_type = 'top200' and data_volume <> 'insufficient'   -- tiny months would make the deltas meaningless
order by year_month
```
